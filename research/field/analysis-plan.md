# Field analysis plan

The participant/session is the primary analysis unit; clips are used only for instructor cue review. Report numerator and denominator, failures, abstentions, rescues, exclusions, and reasons. Report median setup time and participant-cluster bootstrap 95% intervals for proportions using a frozen seed and 10,000 resamples. Do not tune thresholds on the locked field set. Software failures become minimal replay fixtures; changed UX or thresholds require a new cohort for new claims.
