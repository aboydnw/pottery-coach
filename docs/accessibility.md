# Accessibility statement

The controlled prototype uses semantic headings, labels, status/alert announcements, keyboard-operable controls, visible focus, captions/status text for nonvisual system state, non-color confidence language, reduced-motion support, and controls with a minimum 44 px target height. The core setup screen is automatically checked for serious axe violations, narrow-width overflow, keyboard entry, and a 200% text-size proxy.

VoiceOver on iPhone and TalkBack on Android remain part of the consolidated physical test. Until both critical paths pass, mobile accessibility support is pending rather than claimed.
