# Wobble rig protocol

Use a measured eccentric form with dial-indicator amplitudes 0/2/5/10/20 mm and independently measured wheel periods. Include static and moving-camera negatives, monotonic shaping, hand/tool gaps, asymmetric forms, light change, and dropped frames. Freeze labels and splits before evaluation. The locked set must include real consented clips and matched negatives; synthetic output validates machinery but cannot pass Gate 3.
