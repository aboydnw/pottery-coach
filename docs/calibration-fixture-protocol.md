# Calibration and dimension fixture protocol

Print the versioned board at 100% scale and verify the reference line with a traceable ruler. For each supported vessel size, camera offset, angle, and board placement, create five independent setups rather than repeated frames from one setup. Record board revision/checksum, ground truth, device/browser, lighting, exclusions, and consent. Freeze the manifest before scoring. Report all signed errors, unmeasurable outputs, supported acceptance, and unsupported rejection; do not discard failures after inspection.
